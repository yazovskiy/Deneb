# Участие в разработке

Спасибо за интерес к Deneb! Для заметных изменений сначала откройте issue с описанием задачи.

1. Создайте fork и отдельную ветку.
2. Используйте SDK из `global.json`; не обновляйте зависимости без необходимости.
3. Изменения движка сопровождайте тестами на локальном HTTP-сервере, без приватных URL.
4. Выполните `dotnet test Deneb.slnx` и, для изменений интерфейса, PTY-проверку из руководства.
5. Опишите поведение до/после в pull request и обновите документацию.

Сохраняйте разделение ядра и интерфейса. Безопасность докачки, сохранность файлов и отсутствие токенов в сообщениях важнее оптимизации скорости.

Не добавляйте в Git сборки, state.json, части загрузок, секреты и личные файлы.
