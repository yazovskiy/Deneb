## Deneb 2.0: фон и соединения

**Q / Ctrl+C закрывает только интерфейс.** Загрузки продолжаются после закрытия Terminal. Повторный запуск `deneb` подключается к очереди; **F10** останавливает весь Deneb после подтверждения.

- `deneb start` — запустить фон без интерфейса.
- `deneb status` — показать состояние, не запуская фон.
- `deneb pause` / `deneb resume` — включить / снять только общую паузу.
- `deneb stop` — сохранить прогресс и остановить фон.
- Все команды принимают `--state-dir ПУТЬ`. Разрешён один интерфейс на очередь; CLI доступен параллельно.
- При потере связи: **F11** — подключиться; **F12** — запустить фон при необходимости и подключиться. Не повторяйте команду с неизвестным результатом, пока не проверите состояние.

В F2 настройка **«Макс. соединений на файл»** применяется к активным и будущим загрузкам. Диапазон 1–16, по умолчанию 4. Отображается фактическое число / максимум. Сервер, размер меньше 16 МиБ, малый остаток или ожидание повторов могут ограничить число запросов. Изменение лимита не сбрасывает прогресс и паузы.

Перед обновлением закройте Deneb 1.x или выполните `deneb stop` для 2.x. Хранилище обновляется до v4 с отдельной копией исходной версии. Существующие части не переименовываются. **Резервная копия метаданных не гарантирует откат к 1.2 после переразбиения диапазонов.**

Автозапуск при входе, предотвращение сна и автоматический перезапуск после сбоя не включены. Фон работает до явной остановки, даже при пустой очереди.

Ядро и IPC включены в CI-матрицу macOS/Linux/Windows. Официальный бинарник пока только macOS ARM64; Windows/Linux ещё не объявлены пользовательскими платформами.

# Руководство Deneb 1.2

## Выбор языка

В версии 1.2 язык по умолчанию — английский, включая обновление с 1.1. Откройте F2, перейдите Tab к **Language / Язык**, выберите English или Русский стрелками и пробелом, затем сохраните. Переключение применяется сразу, не меняя очередь и паузы.

Язык сохраняется в хранилище v4. При миграции создаётся копия `state.json.v1.bak`, `state.json.v2.bak` или `state.json.v3.bak` согласно исходной версии. `--help` читает язык без запуска движка и изменения хранилища; если чтение невозможно, используется английский.

## Новое в 1.1

- `Insert` отмечает строки; `Space` и `Delete` действуют на отметки, без отметок — на текущую строку. Если среди выбранных есть активные/ожидающие, Space ставит их на ручную паузу; иначе продолжает паузы и ошибки. Требующие решения и завершённые пропускаются.
- `F3` / `F4` перемещают текущую задачу выше/ниже, `F5` ставит её первой. Активные передачи не прерываются; ручная пауза не снимается. Порядок сохраняется.
- `F6` останавливает/продолжает всю очередь. Общая пауза сохраняется после перезапуска и распространяется на новые задачи; ручные паузы независимы.
- `Enter` открывает живые подробности: фаза, сегменты, повторы и время ожидания. «Начать заново» доступно для задач, требующих решения.
- Для готового файла: `O` — открыть, `F7` — показать в Finder, `F8` — скопировать путь. Эти же кнопки есть в подробностях.
- `F9` очищает завершённые записи после подтверждения, не удаляя файлы. `F1` показывает все клавиши. На клавиатуре Mac для F-клавиш может потребоваться Fn; Insert обычно доступен через Fn+Return либо назначение клавиши терминала.
- В 2.0 хранилище обновляется до v4. Не открывайте его старым Deneb: после переразбиения одной копии метаданных недостаточно для безопасного отката.

Полноэкранный менеджер HTTP/HTTPS-загрузок на .NET 10 для macOS Apple Silicon.
Очередь, параллельные соединения, пауза, докачка и восстановление после перезапуска.

## Запуск

Готовая автономная сборка (установка .NET не требуется):

```sh
./artifacts/osx-arm64/deneb
```

Из исходников с SDK .NET 10.0.300:

```sh
dotnet restore Deneb.slnx
dotnet run --project src/Deneb.App
```

Откройте обычный интерактивный терминал; рекомендуемый размер — не меньше 120×35 символов.
`--help` и `--version` работают также без интерактивного терминала.
`--state-dir /absolute/path` запускает приложение с отдельным хранилищем для тестов.

## Управление

| Клавиша | Действие |
|---|---|
| ↑ / ↓ | Выбор задачи |
| A | Добавить ссылки: вставьте текст, Tab переключает поля, Enter на кнопке открывает предварительный просмотр |
| Space | Пауза / продолжение выбранной задачи |
| Enter | Подробности, последняя ошибка; для спорной докачки — начать заново |
| U | Заменить URL выбранного файла |
| Delete | Убрать задачу; части сохраняются по умолчанию |
| F2 | Настройки |
| Esc | Закрыть диалог |
| Q / Ctrl+C | Закрыть интерфейс; загрузки продолжаются |
| F10 | Остановить весь Deneb с подтверждением |
| F11 / F12 | При потере связи: подключиться / запустить фон и подключиться |

Принимаются прямые HTTP/HTTPS-ссылки по одной на строку и строки Android Download Manager вида:

```text
Row: 0 _id=7, title=Пример.mp4, uri=https://example.org/video.mp4, status=192, bytes_so_far=123, total_size=456
```

Можно вставлять Markdown-ссылки и экранированные строки из переписки. Импортируются **только URL и имя**: счётчики Android не означают наличие данных на Mac.
Перед добавлением показываются распознанные ссылки и имена. Необязательное поле «Имя» применяется к одной ссылке.

## Загрузки и докачка

- По умолчанию: 2 файла одновременно, до 4 соединений на файл, папка `~/Downloads/Deneb`.
- Параллельные диапазоны применяются к файлам от 16 МиБ, если сервер подтверждает Range, сообщает размер и валидатор. Иначе — одно соединение.
- Число потоков меняется для новых задач; уже созданные сегменты сохраняют свою структуру. Лимит активных файлов учитывается при запуске очередной задачи.
- Повторы: до 10 после первой попытки, задержка 1–60 секунд; `Retry-After` сервера имеет приоритет. Тайм-аут соединения — 20 секунд, заголовков и отсутствия входящих данных — 30 секунд.
- При выходе активные задачи сохраняются для автоматического продолжения. Пауза, выставленная пользователем, сохраняется.
- Без сильного ETag используется Last-Modified и размер. Если нельзя подтвердить прежний файл или сервер игнорирует Range, Deneb предлагает решение, не дописывая новый ответ к старым данным.
- HTTP 401/403 требует проверки доступа или замены ссылки; это не обязательно истёкший URL.
- После подтверждённого «Начать заново» старые части сохраняются в отдельной папке `.deneb-<id>.saved-<suffix>` рядом с загрузкой. Это резерв, который можно убрать вручную после проверки нового файла.
- Готовый файл появляется только после сборки частей, проверки размера и вычисления SHA-256. Существующие файлы не перезаписываются: добавляется числовой суффикс.
- Во время сборки временно требуется место и для частей, и для итогового файла — примерно двойной размер загрузки.

Скорость — скользящее окно последних пяти секунд; после пяти секунд без данных она равна нулю. ETA появляется после двух секунд измерений при известном размере и передаче данных; длительности больше суток включают дни. При паузе, сборке и неизвестном размере ETA не показывается.

## Состояние и восстановление

На Mac настройки и очередь находятся в `~/Library/Application Support/Deneb`:

- `state.json` — версионированное состояние;
- `state.json.bak` — резервная копия;
- `instance.lock` — блокировка второго процесса с этим хранилищем.

Сегменты находятся в `.deneb-<id>` внутри папки назначения. Каждые 2 секунды данные сбрасываются на диск, затем фиксируется прогресс. При аварийном завершении хвост после последнего сохранённого смещения отбрасывается и скачивается повторно. Отсутствие уже зафиксированных байтов требует решения пользователя.

Ошибка сохранения состояния показывается в нижней строке и блокирует запуск новых задач. После устранения причины можно повторно сохранить настройки; перед закрытием убедитесь, что ошибка исчезла.

URL могут содержать токены, поэтому каталог состояния доступен только владельцу. Отдельный журнал с полными адресами не ведётся. В таблице и подробностях показывается только хост; полный URL — в формах добавления и замены.

## Разработка и проверка

```sh
dotnet test Deneb.slnx
dotnet build src/Deneb.App
python3 scripts/tui-smoke.py src/Deneb.App/bin/Debug/net10.0/deneb
dotnet publish src/Deneb.App -c Release -r osx-arm64 --self-contained true \
  -p:PublishSingleFile=true -o artifacts/osx-arm64
```

Если NuGet v3 недоступен в текущей сети, для restore/publish можно добавить `--source https://www.nuget.org/api/v2/`.
Версии NuGet закреплены в проектах и `packages.lock.json`; проверка воспроизводимости — `dotnet restore --locked-mode`.

`Deneb.Core` содержит планировщик, HTTP-движок, парсер и хранилище. `Deneb.App` — интерфейс Terminal.Gui 1.19.0 (стабильная ветка v1). Тесты xUnit поднимают локальный Kestrel с детерминированными файлами; внешние сервисы и пользовательские ссылки не используются.

Автоматические тесты проверяют SHA-256, сегменты, разрывы, повторы, Range/416, отказ доступа, замену URL, отсутствие валидаторов, очереди, ошибки диска и восстановление контрольных точек, а также миграцию v3, локализации EN/RU, общую паузу, приоритеты, независимые повторы сегментов, расчёт скорости и системные команды через подменяемый адаптер. PTY smoke-test проверяет настоящий полноэкранный интерфейс: формы, две локальные ссылки, отметки, перестановку, общую паузу, живые подробности, смену языка, перезапуск, SHA-256 и очистку записей с сохранением файлов. Для него нужен только Python 3 со стандартной библиотекой; последний аргумент `en` или `ru` задаёт начальный язык.

Проверка именно в Terminal.app остаётся ручной: открыть приложение, добавить две тестовые ссылки, поставить одну на паузу, выйти и запустить снова. Ранее активная задача должна продолжиться, приостановленная — остаться на паузе. Автоматизированный доступ к Terminal.app в среде разработки заблокирован.

Для 1.1 дополнительно проверить `O`, `F7` и `F8` на готовом файле: открытие в стандартном приложении, выделение в Finder и вставку скопированного пути. Затем проверить F6 с одной ручной паузой и перезапуском: общий запрет сохраняется, после его снятия ручная пауза остаётся.

Нет ADB, торрентов, браузерных расширений, поиска видеопотоков, Cookie и произвольных заголовков авторизации. Автозапуск при входе и предотвращение сна не включены. Ядро и локальное управление переносимы; CI настроен на три ОС, официальный выпуск пока ориентирован на macOS ARM64.
